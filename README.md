# TokAi

TikTok 增强模块：界面与播放设置、内容筛选、下载、AI 回复与评论、语音生成、配置备份和多语言界面。

Android 9+，需要支持 libxposed API 102 的框架。当前适配 TikTok `47.5.3 / 2024705030`（`com.zhiliaoapp.musically`）。

从 [Releases](https://github.com/Xposed-Modules-Repo/io.github.yudigaga.tokai/releases/latest) 安装正式版，在框架中启用并勾选 TikTok，重启后打开「设置与隐私 → TokAi 模块设置」。AI 与语音服务需要自行配置；兼容性受宿主版本、账号及服务权限限制。

源码与构建说明：[yudigaga/TokAi](https://github.com/yudigaga/TokAi)。
